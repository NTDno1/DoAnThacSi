## 1. Tổng quan

### 1.1 Mục đích

Tài liệu này mô tả cách triển khai hệ thống **100% offline** sử dụng Docker trên máy local, bao gồm:

- **LLM (Large Language Model)**: Chạy hoàn toàn local bằng Ollama
- **Embedding Model**: Sử dụng models local như `nomic-embed-text` hoặc `mxbai-embed-large`
- **Vector Database**: PostgreSQL + pgvector
- **Tất cả services đều chạy trên Docker**

### 2.2 So sánh Offline vs Online

| Tiêu chí | OpenAI (Online) | Ollama (Offline) |
|----------|------------------|-------------------|
| **Chi phí** | $0.002-0.01/1K tokens | Miễn phí (chỉ điện) |
| **Bảo mật** | Dữ liệu gửi ra ngoài | 100% local |
| **Latency** | 100-500ms | 50-200ms (local GPU) |
| **Availability** | Phụ thuộc OpenAI | Không phụ thuộc |

| **Setup** | Chỉ cần API key | Cần cài Ollama + download models |
| **Hardware** | Không cần GPU mạnh | Cần GPU/CPU mạnh |

## 3. Ollama - LLM Local

### 3.1 Giới thiệu Ollama

**Ollama** là một công cụ mã nguồn mở cho phép chạy các LLM models trực tiếp trên máy local của bạn. Ollama cung cấp:

- **REST API** tương thích với OpenAI API
- **Model Library** với hàng trăm models có sẵn
- **Docker Support** để deploy dễ dàng
- **GPU Acceleration** (CUDA, Metal, Vulkan)

### 3.2 Ollama Docker Image

```yaml
# Pull và chạy Ollama container
docker pull ollama/ollama:latest

# Chạy với GPU support
docker run -d \
  --name ollama \
  --gpus all \
  -p 11434:11434 \
  -v ollama_data:/root/.ollama \
  ollama/ollama
```

## 4. Cấu hình Embedding Local

### 4.1 Tại sao cần Embedding Local?

Embedding model chuyển đổi text thành vectors (số) để lưu trong vector database. Mỗi khi bạn tìm kiếm, query cũng được chuyển thành vector và so sánh với vectors trong database.

### 4.2 Cấu hình Ollama Embedding Service

```python
# services/embedding/ollama_embedding_service.py
from typing import List
import httpx

class OllamaEmbeddingService:
    """Embedding service sử dụng Ollama local"""
    
    def __init__(
        self,
        base_url: str = "http://ollama:11434",
        model: str = "nomic-embed-text"
    ):
        self.base_url = base_url
        self.model = model
        self.client = httpx.AsyncClient(timeout=60.0)
    
    async def generate_embedding(self, text: str) -> List[float]:
        """Generate embedding cho một đoạn text"""
        
        response = await self.client.post(
            f"{self.base_url}/api/embeddings",
            json={
                "model": self.model,
                "prompt": text
            }
        )
        
        if response.status_code != 200:
            raise Exception(f"Ollama API error: {response.text}")
        
        data = response.json()
        return data["embedding"]
    
    async def generate_embeddings(self, texts: List[str]) -> List[List[float]]:
        """Generate embeddings cho nhiều texts"""
        
        embeddings = []
        for text in texts:
            embedding = await self.generate_embedding(text)
            embeddings.append(embedding)
        
        return embeddings
    
    async def get_embedding_dimension(self) -> int:
        """Lấy dimension của embedding model"""
        # nomic-embed-text: 768 dimensions
        # mxbai-embed-large: 1024 dimensions
        return 768 if self.model == "nomic-embed-text" else 1024
```

### 4.3 LLM Service cho Chat

```python
# services/llm/ollama_llm_service.py
from typing import AsyncIterator, List, Dict, Any
import httpx

class OllamaLLMService:
    """LLM service sử dụng Ollama local"""
    
    def __init__(
        self,
        base_url: str = "http://ollama:11434",
        model: str = "llama3.2:3b",
        temperature: float = 0.3
    ):
        self.base_url = base_url
        self.model = model
        self.temperature = temperature
        self.client = httpx.AsyncClient(timeout=300.0)
    
    async def chat(
        self,
        messages: List[Dict[str, str]],
        system_prompt: str = None
    ) -> Dict[str, Any]:
        """Gửi chat request đến Ollama"""
        
        # Build messages với system prompt
        full_messages = []
        if system_prompt:
            full_messages.append({"role": "system", "content": system_prompt})
        full_messages.extend(messages)
        
        response = await self.client.post(
            f"{self.base_url}/api/chat",
            json={
                "model": self.model,
                "messages": full_messages,
                "stream": False,
                "options": {
                    "temperature": self.temperature
                }
            }
        )
        
        if response.status_code != 200:
            raise Exception(f"Ollama API error: {response.text}")
        
        data = response.json()
        return {
            "content": data["message"]["content"],
            "model": data.get("model", self.model),
            "done": data.get("done", True)
        }
    
    async def chat_stream(
        self,
        messages: List[Dict[str, str]],
        system_prompt: str = None
    ) -> AsyncIterator[str]:
        """Stream chat response từ Ollama"""
        
        full_messages = []
        if system_prompt:
            full_messages.append({"role": "system", "content": system_prompt})
        full_messages.extend(messages)
        
        async with self.client.stream(
            "POST",
            f"{self.base_url}/api/chat",
            json={
                "model": self.model,
                "messages": full_messages,
                "stream": True,
                "options": {
                    "temperature": self.temperature
                }
            }
        ) as response:
            async for line in response.aiter_lines():
                if line:
                    import json
                    try:
                        data = json.loads(line)
                        if "message" in data:
                            yield data["message"]["content"]
                        if data.get("done", False):
                            break
                    except:
                        continue
```

## 9. Migration từ OpenAI sang Local

### 9.1 Service Factory Pattern

```python
# services/ai/ai_service_factory.py
from typing import Protocol
import os

class ILLMService(Protocol):
    async def chat(self, messages: list, system_prompt: str = None) -> dict: ...
    async def chat_stream(self, messages: list, system_prompt: str = None): ...

class IEmbeddingService(Protocol):
    async def generate_embedding(self, text: str) -> list[float]: ...
    async def generate_embeddings(self, texts: list[str]) -> list[list[float]]: ...

class AIServiceFactory:
    """Factory để chọn giữa OpenAI và Ollama"""
    
    @staticmethod
    def create_llm_service() -> ILLMService:
        """Tạo LLM service dựa trên cấu hình"""
        
        # Kiểm tra xem có OpenAI API key không
        openai_key = os.getenv("OPENAI_API_KEY", "")
        
        if openai_key and openai_key.strip():
            # Sử dụng OpenAI
            from services.llm.openai_llm_service import OpenAILLMService
            return OpenAILLMService()
        else:
            # Sử dụng Ollama (offline)
            from services.llm.ollama_llm_service import OllamaLLMService
            return OllamaLLMService(
                base_url=os.getenv("OLLAMA_BASE_URL", "http://ollama:11434"),
                model=os.getenv("OLLAMA_CHAT_MODEL", "llama3.2:3b")
            )
    
    @staticmethod
    def create_embedding_service() -> IEmbeddingService:
        """Tạo Embedding service dựa trên cấu hình"""
        
        openai_key = os.getenv("OPENAI_API_KEY", "")
        
        if openai_key and openai_key.strip():
            from services.embedding.openai_embedding_service import OpenAIEmbeddingService
            return OpenAIEmbeddingService()
        else:
            from services.embedding.ollama_embedding_service import OllamaEmbeddingService
            return OllamaEmbeddingService(
                base_url=os.getenv("OLLAMA_BASE_URL", "http://ollama:11434"),
                model=os.getenv("OLLAMA_EMBEDDING_MODEL", "nomic-embed-text")
            )
```

### 9.2 Configuration Class

```python
# core/config/ai_config.py
from pydantic import BaseModel
from typing import Optional
import os

class LLMConfig(BaseModel):
    """LLM Configuration - hỗ trợ cả Online và Offline"""
    
    # Provider selection
    provider: str = "ollama"  # "openai" hoặc "ollama"
    
    # OpenAI settings (nếu sử dụng)
    openai_api_key: Optional[str] = None
    openai_chat_model: str = "gpt-4o-mini"
    openai_embedding_model: str = "text-embedding-3-small"
    
    # Ollama settings (nếu sử dụng)
    ollama_base_url: str = "http://ollama:11434"
    ollama_chat_model: str = "llama3.2:3b"
    ollama_embedding_model: str = "nomic-embed-text"
    ollama_temperature: float = 0.3
    ollama_max_tokens: int = 2000
    
    @classmethod
    def from_env(cls) -> "LLMConfig":
        """Load config từ environment variables"""
        openai_key = os.getenv("OPENAI_API_KEY", "")
        
        if openai_key and openai_key.strip():
            provider = "openai"
        else:
            provider = "ollama"
        
        return cls(
            provider=provider,
            openai_api_key=openai_key or None,
            openai_chat_model=os.getenv("OPENAI_CHAT_MODEL", "gpt-4o-mini"),
            openai_embedding_model=os.getenv("OPENAI_EMBEDDING_MODEL", "text-embedding-3-small"),
            ollama_base_url=os.getenv("OLLAMA_BASE_URL", "http://ollama:11434"),
            ollama_chat_model=os.getenv("OLLAMA_CHAT_MODEL", "llama3.2:3b"),
            ollama_embedding_model=os.getenv("OLLAMA_EMBEDDING_MODEL", "nomic-embed-text"),
            ollama_temperature=float(os.getenv("OLLAMA_TEMPERATURE", "0.3")),
            ollama_max_tokens=int(os.getenv("OLLAMA_MAX_TOKENS", "2000"))
        )
    
    @property
    def is_offline(self) -> bool:
        """Kiểm tra xem có đang chạy offline không"""
        return self.provider == "ollama"
```

## 10. Troubleshooting

### 10.1 Common Issues

| Issue | Cause | Solution |
|-------|-------|---------|
| Ollama container không start | GPU drivers chưa cài | Cài NVIDIA drivers hoặc chạy CPU mode |
| Model download chậm | Kết nối mạng chậm | Dùng `ollama pull` trực tiếp hoặc tải trước |
| Out of memory (GPU) | Model quá lớn cho VRAM | Giảm model size hoặc tăng swap |
| Embedding dimension mismatch | Sai model | Kiểm tra `OLLAMA_EMBEDDING_MODEL` env var |
| Slow inference (CPU) | CPU yếu | Dùng model nhỏ hơn: `llama3.2:1b` |
| Container can't reach Ollama | Network issue | Kiểm tra `ollama` service trong docker-compose |
